Implement:

- `int insertion_sort(int *a, int n)` sorts `a` ascending in place and returns the number of times an element was shifted one slot right (equivalently, the number of inversions in the original array). `n` may be 0 or 1.
- `void insertion_sort_strs(const char **a, int n)` sorts an array of strings ascending by `strcmp`, moving the pointers (not the characters).

Do not allocate memory. Equal elements must stay in their original order (use a strict comparison).
