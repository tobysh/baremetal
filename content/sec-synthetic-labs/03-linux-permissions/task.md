Implement `AuditTar(data []byte) ([]Finding, error)` using Go's archive/tar. Each Finding has Path and Kind. Report `world-writable` for any regular file with mode & 0002 != 0; `root-suid` for UID 0 regular files with mode & 04000 != 0 and at least one execute bit; `exposed-secret` for regular paths ending `.key` or `/shadow` with any group/other read bit (0044). A file can produce multiple findings. Sort by Path then Kind. Return an error on invalid tar. `filesystem.tar` is the public archive: `tmp/note` is world-writable, `usr/bin/helper` is root-suid, and `etc/service.key` is exposed-secret. Hidden tests pass other archives directly to the function.
