Implement `Subnet(cidr string) (Network, error)` and `NextHop(ip string, routes []Route) string`. Network includes Network, Broadcast, First, Last (dotted IPv4) and Usable (uint64). CIDR may contain host bits. Reject invalid input and IPv6. Routes have valid IPv4 prefixes and arbitrary Hop labels. Return `""` for invalid destinations or no match. Example: `192.0.2.129/25` gives network `.128`, broadcast `.255`, first `.129`, last `.254`, 126 hosts.
