Implement `ForgeCookie(known string, candidates []string, desired string) (string, error)`. Decode the known body with unpadded URL base64; compare candidate HMACs with its hex signature. Return a cookie for exactly desired using the matching key. Return an error for malformed cookies or if no candidate matches. Example body: `user=guest&role=reader`; desired: `user=guest&role=admin`. The candidate list changes in hidden tests.
