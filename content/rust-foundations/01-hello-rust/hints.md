Create three variables, for example `let language = "Rust";`, `let edition = 2021;` and `let safe = true;`.
===
Each line is one `println!`, with the label as literal text and `{}` where the value goes: `println!("Language: {}", language);`
===
`true` prints as `true` with `{}`, so no conversion is needed. You need three `println!` calls, one per line, in the order shown.
