`Pair` is defined in the starter: two fixed arrays, `key[16]` and `value[16]`, so each can hold up to 15 characters plus the `'\0'`. Implement (include `<stdio.h>` and `<string.h>`):

- `int format_time(char *buf, size_t cap, int total_seconds)` writes `total_seconds` as `HH:MM:SS` with two-digit zero padding, for example `3661` gives `"01:01:01"` and `0` gives `"00:00:00"`. Hours may be more than two digits (`360000` gives `"100:00:00"`). Use `snprintf`. Return `0` if it fit completely. Return `-1` if `total_seconds` is negative (and make `buf` an empty string if `cap > 0`), or if the text did not fit in `cap` (the buffer must still hold a valid, truncated string when `cap > 0`).
- `int format_pairs(char *buf, size_t cap, const Pair *pairs, int n)` writes every pair as `key=value;` one after the other, for example `"a=1;b=2;"`. Returns the length of the text on success (`0` for `n == 0`, with `buf` set to `""`). Returns `-1` if the text does not fit, or `cap` is `0`. After a `-1` with `cap > 0`, `buf` must still be a valid string.
- `int parse_pairs(const char *text, Pair *out, int max)` reads text of the form `key=value;key=value;` into `out` and returns how many pairs it read. Rules: the last `;` is optional; a value may be empty (`"a=;"` is one pair with value `""`); an empty `text` has `0` pairs. Return `-1` for malformed text: a pair with no `=` (including leftover characters like `"a=1;b"`), an empty key (`"=1"`, `";"`, `"a=1;;b=2"`), an `=` inside a value (`"a=b=c"`), a key or value longer than 15 characters, or more than `max` pairs. Characters other than `=` and `;` have no special meaning, including spaces.
