The input is any number of whole numbers separated by spaces or newlines, possibly none. There is no upper limit on how many, so do not assume one.

Read all of them, then print the numbers in reverse order, one per line, last number first. After those, print one final line saying how many of the numbers were strictly greater than the exact average of all of them:

```
above average: 2
```

With no numbers, print only the final line, with a count of 0. A number that equals the average is not above it. Every number fits in an `int`. Your program is tried on many different inputs, including long ones.

The file starts with only the `#include` lines. Choose your own functions and write `main` yourself.
