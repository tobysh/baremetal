`Elf64_Ehdr`, `Elf64_Phdr`, `PT_LOAD` and the `ELF_*` return codes are in the starter. Implement:

- `int elf_validate(const uint8_t *image, size_t size)` returns `ELF_OK` (0) or the **first** error found, in this order: `ELF_E_SMALL` (fewer than 64 bytes), `ELF_E_MAGIC`, `ELF_E_CLASS` (not 64-bit little endian), `ELF_E_TYPE` (not type 2), `ELF_E_MACHINE` (not 62), `ELF_E_PHDR` (`e_phentsize` is not 56, or the program header table does not fit inside the file, computed without overflow).
- `int elf_load(const uint8_t *image, size_t size, uint8_t *memory, size_t mem_size, uint64_t mem_base, uint64_t *entry)` runs `elf_validate` and returns its error if any. Then, for every `PT_LOAD` segment, it checks `filesz <= memsz` and that the file range is inside the image (`ELF_E_SEGMENT`), and that `[vaddr, vaddr + memsz)` is inside `[mem_base, mem_base + mem_size)` (`ELF_E_RANGE`); and checks that `e_entry` is inside some loaded segment (`ELF_E_ENTRY`). Only if all checks pass does it copy each segment to `memory + (vaddr - mem_base)` and zero the bss tail, store the entry in `*entry`, and return `ELF_OK`. On any error `memory` must be left untouched. Segments of other types are ignored.
