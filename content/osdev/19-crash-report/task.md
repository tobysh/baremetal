The helpers `put_str`, `put_dec` and `put_hex` (each `size_t fn(char *out, size_t cap, size_t pos, ...)` returning the new length) are in the starter. Implement:

- `const char *exception_name(unsigned vector)` returns `"Divide Error"`, `"Debug"`, `"Non-Maskable Interrupt"`, `"Breakpoint"`, `"Overflow"`, `"Bound Range Exceeded"`, `"Invalid Opcode"`, `"Device Not Available"`, `"Double Fault"`, `"Coprocessor Segment Overrun"`, `"Invalid TSS"`, `"Segment Not Present"`, `"Stack-Segment Fault"`, `"General Protection Fault"`, `"Page Fault"` for vectors 0 to 14, then `"Reserved"` for 15, `"x87 Floating-Point Exception"` (16), `"Alignment Check"` (17), `"Machine Check"` (18), `"SIMD Floating-Point Exception"` (19), `"Virtualization Exception"` (20), `"Control Protection Exception"` (21), `"Reserved"` for 22 to 31 and `"External Interrupt"` for 32 and above.
- `int exception_has_error_code(unsigned vector)` is 1 for vectors 8, 10, 11, 12, 13, 14, 17, 21, 29 and 30, otherwise 0.
- `void describe_page_fault(uint64_t err, char *out, size_t cap)` writes `"<access> a <state> page from <mode> mode"`. The access is `fetch from` if bit 4 is set, otherwise `write to` if bit 1 is set, otherwise `read from`. The state is `protected` if bit 0 is set, else `non-present`. The mode is `user` if bit 2 is set, else `kernel`. If bit 3 is set, add `, reserved bit set` at the end. Example: `"write to a non-present page from kernel mode"`.
- `void describe_selector_error(uint64_t err, char *out, size_t cap)` writes `"no selector"` when `err` is 0. Otherwise it writes `"<table> index <n>"` with the table `GDT` (bits 1-2 = 0), `IDT` (1 or 3) or `LDT` (2), and `n` the index (`err >> 3`) in decimal, followed by `" (external)"` if bit 0 is set. Example: `"GDT index 5"`.
- `void format_crash(char *out, size_t cap, uint64_t vec, uint64_t err, uint64_t rip, uint64_t cr2)` writes `"<name> (vector <vec>) at <rip>"` with `rip` in hex via `put_hex` (which adds `0x`). Then: for vector 14 append `": "`, the page-fault description, `", address "` and `cr2` in hex; for vectors 10 to 13 with a non-zero `err` append `": "` and the selector description; otherwise nothing more. Example: `"Page Fault (vector 14) at 0x101234: read from a non-present page from kernel mode, address 0x0"`.
- `void crash_init(void)` makes your handler the kernel's exception handler: set `bm_exception_hook` to a function that reads CR2 and stores a `format_crash` report in a static 160-byte buffer. `const char *crash_last_report(void)` returns that buffer (an empty string before any exception).
