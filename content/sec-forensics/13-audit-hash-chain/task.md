Read stdin (at most 500 lines, each at most 300 characters). Line N (starting at 1) must be four `|`-separated fields `SEQ|ACTOR|ACTION|HASH`: SEQ is a positive decimal number without leading zeros, ACTOR and ACTION are non-empty (and contain no `|`), HASH is exactly 16 lowercase hex digits. Entry sequence numbers must run 1, 2, 3, and so on. The expected hash of an entry is the 16 digit lowercase hex form (`%016llx`) of FNV-1a 64 (offset basis 14695981039346656037, multiplier 1099511628211) over the bytes of `PREV|SEQ|ACTOR|ACTION`, where PREV is the previous entry's HASH text, or `0000000000000000` for the first. Checks per line in this order: malformed, then sequence, then hash. On the first failure print exactly one of `BROKEN at line N: malformed`, `BROKEN at line N: sequence (expected E, found F)` or `BROKEN at line N: hash mismatch` and stop. Blank lines are malformed. If all lines pass print `chain ok: K entries head=H` (H is the last hash, or sixteen zeros for empty input).

Tests use several different logs. Keep the supplied function names and types.
