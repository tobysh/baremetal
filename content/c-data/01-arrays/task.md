- `int array_sum(int a[], int n)` returns the sum of the `n` elements. An empty array (`n` of 0) sums to 0.
- `int array_max(int a[], int n)` returns the largest element. `n` is at least 1. The elements may all be negative.
- `int count_above(int a[], int n, int limit)` returns how many elements are strictly greater than `limit`.
