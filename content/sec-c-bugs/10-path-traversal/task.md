Implement `int clean_path(const char *in,char *out,size_t cap)`. Return 1 and write the normalised path to `out` on success, otherwise return 0 and (if `cap>0`) set `out[0]=0`. Rules: `in` must start with `/`; reject a backslash, any byte below 0x20 or 0x7f anywhere in `in`; skip empty and `.` segments; `..` removes the previous segment and rejects the path when there is nothing to remove; `...` and `..a` are ordinary names. The result starts with `/`, has single slashes between segments and no trailing slash (the empty path is `/`). The result plus its terminating zero must fit in `cap`, else fail. NULL `in` or `out`, or `cap==0`, fail without writing.

Tests use many fixed and generated paths and watch the bytes after the buffer. Keep the supplied function names and types.
