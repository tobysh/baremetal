The input is any number of integers separated by spaces or newlines, possibly none. Read them all, then print:

```
count: 4
sum: 17
max: 9
```

(That is for the input `3 9 -2 7`.) If there are no numbers, print `count: 0`, `sum: 0` and `max: none`.

Other inputs are tried, including lists of only negative numbers and empty input.
