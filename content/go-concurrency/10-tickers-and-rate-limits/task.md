- `RateLimited(in <-chan int, every time.Duration) <-chan int` returns a channel that forwards the values of `in` in order, **waiting for one tick of period `every` before each value**, so values leave at most once per interval. It closes its output when `in` is closed and drained. Return right away; do the work in a goroutine, and stop the ticker when done.
- `Poll(ctx context.Context, every time.Duration, check func() bool) bool` calls `check` once per tick (the first call happens after one `every`, not immediately). It returns `true` as soon as `check` returns `true`, or `false` when `ctx` is done first. Stop the ticker before returning.
