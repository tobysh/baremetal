- `CallWithTimeout(d time.Duration, f func(ctx context.Context) (string, error)) (string, error)` runs `f` with a context that times out after `d`, and returns what `f` returns. If the time runs out first it must return `context.DeadlineExceeded` right away **even if `f` ignores its context** and keeps running. Run `f` in its own goroutine and make sure it can finish later without leaking.
- `Remaining(ctx context.Context) (time.Duration, bool)` returns how long is left until the deadline and `true`, or `0, false` when `ctx` has no deadline. A deadline in the past gives `0, true` (never a negative duration).
- `Half(ctx context.Context) (context.Context, context.CancelFunc)` returns a child context that has **half of the remaining time** of `ctx`. If `ctx` has no deadline, the child has none either. The returned cancel function must always be safe to call.
