Stdin: the first line is the server key, then at most 100 token lines. A token must have exactly two dots with a non-empty header part and payload part (the signature part may be empty). Both parts must decode with strict base64url (starter). The decoded header is `key=value` pairs separated by `;` with non-empty keys and no duplicate keys. For token N print `token N: <verdict>` where the verdict is the first that applies: `malformed` (structure, base64url or header syntax), `bad-alg` (no `alg` key, or its value is not exactly `HS256`), `bad-signature` (the signature is not exactly the 16 lowercase hex characters of the toy MAC over `header.payload` as received), otherwise `ok`.
