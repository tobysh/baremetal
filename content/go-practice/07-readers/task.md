- `ParseKV(r io.Reader) (map[string]string, error)` reads `key = value` lines. Blank lines and lines whose first non-space character is `#` are ignored. Keys and values are trimmed of surrounding spaces. A later duplicate key replaces the earlier one. A value may be empty, and may itself contain `=` (only the first one splits). A line with no `=`, or with an empty key, is an error: return `nil` and an error whose text is `line N: ` followed by `missing '='` or `empty key` (N counts every line from 1).
- `Stats(r io.Reader) (lines, words, bytes int, err error)` is a tiny `wc`: the number of lines (a final line without a newline still counts; empty input has 0), the number of whitespace-separated words, and the number of bytes. Read the input once; hint: wrap the reader with `io.TeeReader` or count as you scan.
