The flags `PTE_P`, `PTE_W`, `PTE_U`, `ADDR_MASK`, `USER_BASE` and `USER_END`, the frame pool (`frame_alloc`, `frame_free`, `frames_in_use`, `bad_frees`), `kernel_pml4`, `current_as` (both set by `aspace_boot`, which the tests call first), `map_page(pml4, virt, phys, flags)` and `leaf_pte(pml4, virt)` are in the starter. Addresses of frames and tables are plain pointers (physical memory is identity-mapped). Implement:

- `uint64_t aspace_create(void)` allocates a frame for a new PML4 and copies entry 0 from `kernel_pml4`. Every other entry stays zero. Returns the PML4's address, or 0 if no frame is left.
- `uint64_t aspace_alloc_page(uint64_t as, uint64_t virt, int writable)` maps a fresh frame at `virt` in space `as` with `PTE_U`, plus `PTE_W` if `writable`, and returns the frame's address. It returns 0, without leaking a frame, if `virt` is not page-aligned, is outside `[USER_BASE, USER_END)`, is already mapped, or memory is out of frames.
- `void aspace_switch(uint64_t as)` loads `as` into `cr3` and records it in `current_as`.
- `int aspace_copy_to(uint64_t as, uint64_t virt, const void *src, size_t len)` copies `len` bytes to user address `virt` in space `as`, which need not be the current one, and returns 0. It returns -1 and writes nothing if any byte of the range is not mapped, or if the range is not inside the user half (watch for overflow). `len == 0` returns 0.
- `unsigned aspace_destroy(uint64_t as)` frees every user data frame, every page-table frame below PML4 entries 1 to 511, and the PML4 itself, and returns how many frames it freed. It must not free anything reachable through entry 0. If `as` is `current_as`, it first switches to `kernel_pml4`. Destroying `kernel_pml4` does nothing and returns 0.
