Implement `pipe_init`, `pipe_write`, `pipe_read` and `pipe_close_writer`. Capacity is 16 bytes. Read and write return the number transferred (possibly partial). Read returns -1 only when empty and the writer is open, and 0 at EOF. Write returns -1 after close. Zero-length reads and writes return 0 while open; a write after close returns -1 even for zero length. Buffers are valid and disjoint from the pipe.
