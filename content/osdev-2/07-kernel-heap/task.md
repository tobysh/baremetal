Implement `heap_init`, `heap_alloc(size_t n)` and `heap_free(void *p)`. The arena has 256 bytes and 32 descriptors. Allocation uses first fit, rounds up to 8 bytes, returns NULL for zero, overflow, no fit or insufficient descriptors to split, and leaves state unchanged on failure. Free returns 0 for the start of a live allocation, otherwise -1. Coalesce adjacent free blocks. Tests use different sizes, fragmentation and invalid frees.
