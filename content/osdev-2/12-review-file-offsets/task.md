Implement `files_init`, `file_open`, `file_read`, and `file_close`. Init fills the 32-byte file with values 0 through 31 and closes all descriptors. Open chooses the lowest free descriptor and starts its offset at zero, returning -1 if full. Read returns the bytes transferred, stopping at EOF, and advances the descriptor offset. Invalid or closed descriptors return -1. A zero-length read on a valid descriptor returns 0. Close returns 0 on success and -1 for an invalid or closed descriptor. Tests open several descriptors, exhaust and reuse slots, and read through EOF.
