The GDT and TSS from the last lesson (`gdt_setup`, written compactly), the IDT (`idt`, `idt_init`), `make_low_memory_user`, `trap_stack`, `USER_CS` (`0x23`), `USER_SS` (`0x1B`) and the globals `saved_kernel_sp`, `in_user`, `last_trap_rip` and `last_trap_error` are in the starter. Implement:

- `uint64_t *build_iret_frame(uint64_t *stack_top, uint64_t rip, uint64_t user_rsp)` writes the five-slot iretq frame just below `stack_top`: `ss` highest, then `rsp`, `rflags` (`0x2`: interrupts off), `cs`, and `rip` lowest. It returns a pointer to the `rip` slot (that is, `stack_top - 5`). It does not touch anything at or above `stack_top`.
- `uint64_t enter_user(uint64_t *frame)` in the assembly block: push `rbp`, `rbx`, `r12` to `r15`, store `rsp` in `saved_kernel_sp`, set `rsp` to `frame` (in `rdi`) and `iretq`.
- `void leave_user(uint64_t value)` in the assembly block: restore `rsp` from `saved_kernel_sp`, pop the six registers in reverse, put `value` in `rax` and `ret`. It never returns to its own caller.
- `void user_trap(uint64_t vector, uint64_t error_code, uint64_t rip)` is the exception hook. If `in_user` is 0 it reports the exception with `bm_exception(vector, error_code, rip, 0)` (a kernel bug). Otherwise it clears `in_user`, stores `error_code` and `rip` in `last_trap_error` and `last_trap_rip`, and calls `leave_user(vector)`.
- `uint64_t run_user(void (*entry)(void), uint64_t user_stack_top)` builds the frame with `build_iret_frame` in the provided `iret_area` (its top is `iret_area + 5`), sets `in_user` to 1, calls `enter_user` and returns what it returns: the vector that ended the program.
- `void user_init(void)` calls `gdt_setup` with the top of `trap_stack`, then `idt_init`, opens **vector 47 to ring 3** by giving `idt[47]` the type byte `0xEE`, masks every IRQ on both PICs (`0xFF` to ports `0x21` and `0xA1`), calls `make_low_memory_user` and installs `user_trap` as `bm_exception_hook`.
