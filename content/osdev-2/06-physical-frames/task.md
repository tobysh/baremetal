Implement `frame_init`, `frame_reserve(first, count)`, `frame_take` and `frame_release(addr)`. There are 64 frames of 4096 bytes beginning at `BASE`. Init clears the bitmap. Reserve marks the intersection of `[first, first+count)` with the pool; avoid unsigned overflow. Take returns the lowest free address or zero. Release returns 0 for a currently allocated or reserved frame in the pool, clearing its bit; otherwise return -1 without changing state. Tests vary ranges and exhaust the pool.
