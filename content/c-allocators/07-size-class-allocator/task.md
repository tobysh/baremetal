Implement classes_init, classes_alloc and classes_free. Initialization resets both pool bitmaps and initializes the supplied heap buffer. Allocation of zero returns NULL; pool allocation chooses the lowest available slot. A pool miss falls back to heap_alloc. Free of NULL returns 0. Pool frees require an exact slot start and a live allocation, otherwise return -1 without changing ownership. Other pointers go through heap_free. Reuse freed pool slots and preserve contents of all live allocations. Callers never free a pointer from an older initialization.
