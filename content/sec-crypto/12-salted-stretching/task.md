FNV-1a 64-bit: start with `h = 14695981039346656037`, and for each byte `h = (h ^ byte) * 1099511628211` (mod 2^64). Implement `uint64_t toy_kdf(const char *pw,const uint8_t *salt,size_t slen,unsigned iters)`. Step 1: feed the salt bytes and then the password bytes (without the terminating zero) into one running FNV-1a hash starting from the offset basis. Step 2: repeat `iters` times (treat 0 as 1): serialise the current value into 8 bytes, least significant byte first, restart FNV-1a from the offset basis, feed those 8 bytes then the salt bytes, and take the result as the new value. Return the final value. A NULL `pw` means the empty password and a NULL `salt` is allowed when `slen` is 0.

Tests use fixed vectors and many generated inputs. Keep the supplied function names and types.
