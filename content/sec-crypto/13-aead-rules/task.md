The starter has the toy cipher (`toy_xor` applies the keystream, `toy_tag` computes a tag over key, nonce, AAD and ciphertext). Do not change it. Three functions use it; the starter versions contain the mistakes above.

1. **`int channel_seal(Channel *ch, const char *aad, const uint8_t *pt, size_t n, Packet *out)`**. Return `-1` and change nothing if `n > 64` or `ch->counter >= ch->limit`. Otherwise use `ch->counter` as the nonce and then increment it, store the nonce and `n` in the packet, encrypt `pt` into `out->ct`, set `out->tag` to `toy_tag(key, nonce, aad, ct, n)` and return `0`. The tag must be computed over the ciphertext that is stored.
2. **`int channel_open(const Channel *ch, const char *aad, const Packet *p, uint8_t *out, size_t outcap)`**. Return `-1` if `p->n > 64` or `p->n > outcap`. Check the tag first, using the packet's nonce and the caller's `aad`; on mismatch return `-1` and **do not write to `out` at all**. Only after the tag matches, decrypt into `out` and return the length (`0` for an empty message).
3. **`int audit_calls(const Call *log, int n, int *kind)`** scans a log of past calls in order. A `Call` has `op` (`'S'` seal or `'O'` open), `key`, `nonce`, `aad_bound` (1 if the AAD was supplied) and `tag_first` (1 if an open checked the tag before decrypting). Return the index of the first misuse and set `*kind`; return `-1` with `*kind = 0` if the log is clean. Kinds: `1` a seal used a `(key, nonce)` pair an earlier seal already used; `2` an open had `tag_first == 0`; `3` any call had `aad_bound == 0`. When one call has several problems, report the lowest kind number that applies. Opens never count towards nonce reuse, and the same nonce under a different key is fine.

Many different channels, packets and logs are tried.
