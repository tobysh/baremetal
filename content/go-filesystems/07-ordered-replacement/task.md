Implement Replacement(old, fresh, value) []Write. old and fresh are distinct nonnegative block numbers, initially old is allocated and initialized, and fresh is free. Emit exactly four writes in this order: reserve fresh (Kind="alloc"), write its contents (Kind="data"), replace the inode pointer (Kind="inode"), free old (Kind="free"). Block identifies the target; Value equals value only for data, and zero for all other writes. Hidden tests cut after every write and check that the pointer always names initialized allocated data.
