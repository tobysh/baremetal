Implement Recover(d *Disk) error. If Journal.Committed is false do nothing. Otherwise validate every record address against len(Home) before writing anything; return ErrJournal on any invalid address. Replay records in order, including duplicate addresses (last value wins). Call d.Write for each record. On error, stop immediately and keep the entire journal for retry. Clear the journal only after all writes succeed. A completed recovery is idempotent. Do not reset the disk’s fault-injection counters.
