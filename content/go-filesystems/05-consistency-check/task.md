Implement Check(image) Report. Data blocks are [DataStart, NBlocks). Bitmap length must equal NBlocks and 0 <= DataStart <= NBlocks; invalid geometry returns BadGeometry with no findings. Each pointer outside the data region produces one Invalid finding (including repeated invalid pointers), sorted numerically. For valid data blocks report Orphan (allocated, zero references), Dangling (free, at least one reference), and Duplicate (two or more references, including within one inode). These three lists are ascending and unique. Ignore metadata bitmap bits. Never mutate input.
