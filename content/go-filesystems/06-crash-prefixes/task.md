Implement UnsafeCuts(initial, writes). State has block allocation bits Used and an inode pointer Ptr (-1 means empty). Writes are either allocation changes (Kind="bit", Block in range, Value 0 or 1) or inode replacement (Kind="ptr", Value -1 or a valid block). Inputs obey these ranges and initial state is consistent. Return every cut k in [0,len(writes)] where the durable pointer names an unallocated block. Orphan allocation is permitted. Do not mutate initial or writes. Return cuts in increasing order.
