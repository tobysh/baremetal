Implement `int popcount64(uint64_t x)` in assembly. It returns the number of bits set to 1 in `x`, from 0 to 64.

`x` arrives in `rdi`; return the count in `eax`. Use only caller-saved registers (`rax`, `rcx`, `rdx`, `rsi`, `rdi`, `r8` to `r11`): the tests check that `rbx`, `rbp` and `r12` to `r15` come back unchanged.
