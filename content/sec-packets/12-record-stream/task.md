Implement `int tls_walk(const uint8_t *b,size_t n,size_t *records,size_t *consumed)`. Starting at offset 0 repeat: if no bytes remain, return 0 (clean end). If fewer than 5 bytes remain, return 1 (incomplete). Otherwise validate the header: type in 20..23, `b[1]==3`, `b[2]` in 1..4, length (big endian, bytes 3 and 4) in 1..16384; a bad header returns -1. If the body is not fully present (`length > remaining-5`) return 1. Otherwise count the record and move past it. On every return set `*records` to the number of complete valid records passed and `*consumed` to the number of bytes they occupy (both may be NULL). NULL `b` with `n>0` returns -1 with both outputs 0.

Tests use many generated streams, including truncated and corrupted ones. Keep the supplied function names and types.
